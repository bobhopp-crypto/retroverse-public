# Retroverse Public

Standalone public landing page for [retroverse.live](https://retroverse.live).

The homepage is a single illustrated interactive poster (`public/retroverse-home.png`). Hotspots overlay search, charts, and feedback areas.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Built for Vercel. Connect the GitHub repo and deploy the `main` branch.

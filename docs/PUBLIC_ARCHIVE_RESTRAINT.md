# Archive Restraint Enforcement Pass

Aggressive preservation of editorial stillness — no redesign, no new modules.

## Restraint findings

| Drift | Action |
|-------|--------|
| Hot 100 badge on track hero | **Removed** — chart rail implies chart context |
| Journey lead paragraph (peak · weeks · date) | **Removed** — rail is the explanation |
| “Open {year} →” CTAs | Link text is **year only** |
| Section `{artist} →` links | **Removed** on track related + album tracklist (footer suffices) |
| “View All →” on artist sections | **All** |
| Chart stat dashboard on artist home | **Removed** — use Charts nav |
| Album shelf peak on every tile | **Year only** |
| “Open album →” | **Album title** as link text |
| Jukebox Year/Peak/Weeks `<dl>` + SongActions | **Restraint mode** on artist: one meta line, no action chrome |

## Utility drift suppressed

- Play/queue/inspect actions on artist song stack
- Duplicate artist navigation (section header + footer)
- Dashboard-style chart highlight counts on main exhibit
- Instructional “Open …” phrasing

## Degraded / healed discipline

| State | Behavior |
|-------|----------|
| Degraded track | Sparse class, plate cover, no filler widgets |
| Degraded album | Sparse when no tracklist/journey |
| Healed track | Appears on list — same density as related songs |
| Healed | No “success” badges or ops indicators |

## Interaction restraint

- Footer remains sole global nav (Home · Search · artist)
- Artist song stack: link to song is the interaction; no secondary action column
- Search jukebox unchanged (search scope not reopened)

## Archive temperature

Warm paper, grain, framed covers, list sections — stillness over hyper-function.
